The wordmark and mark become a logo. Lockups place the mark by its real outline
and switch to a stacked layout when space runs out. Modulation replaces the
prototype's hidden links between parameters. Per-glyph overrides let a designer
fix single letters. The whole state saves to a project file and reopens exactly
as it was.

## Gate

A project saved at any point reopens byte-identical in its rendered scene graph,
including custom formulas, per-glyph overrides and the random seed.
